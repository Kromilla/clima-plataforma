# Plataforma de Clima y Sostenibilidad — Santa Marta

Bot de alertas por Telegram + dashboard de calidad del aire, clima, incendios y energía, para Santa Marta, Colombia (extensible a otros lugares).

Ver `informe-proyecto-clima-v3.md` para la hoja de ruta técnica completa (fases, arquitectura, criterios de aceptación).

## Setup

```bash
python -m venv .venv
.venv/Scripts/activate  # Windows
pip install -r requirements.txt
cp .env.example .env  # y completa las keys
```
